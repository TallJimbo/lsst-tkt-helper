## Why

The list of default tools is hardcoded in the `tkt new` CLI command, so it cannot be customized per user, and `tkt update` never reconciles a workspace's tools with the current defaults. A workspace created before a new default tool was introduced (e.g. `direnv`) keeps it missing forever, and tools removed from configuration linger in the workspace.

## What Changes

- Add a required `default_tools` key to the environment config JSON (e.g. `local.json`) listing the names of tools that should be installed by default. If the key is absent, configuration loading raises an error.
- `tkt new`: start from the config's `default_tools` and adjust per invocation with `--add-tool NAME` (add) and `--remove-tool NAME` (remove). These replace the previous `--tool` option, which overrode (discarded) the configured defaults.
- `tkt update`: reconcile the workspace's stored tools against the config:
  - Tools in `default_tools` but missing from the workspace are proposed for addition via a single interactive prompt that lists them.
  - Tools present in the workspace but no longer configured at all are **removed** with a warning.
  - Tools present in the workspace but simply no longer in the default list (still configured) are left in place.
- In `--dry-run`, reconciliation is logged, not prompted or applied.

## Capabilities

### New Capabilities

- `default-tools`: config-driven default tool list and `tkt update` reconciliation of workspace tools (propose additions interactively, remove unconfigured tools with a warning).

### Modified Capabilities

- `direnv-tool`: update the "Regenerated by workspace commands" scenario that references the removed `--tool` option to reference `default_tools` instead.

## Impact

- `tkt/_cli.py`: `new` computes the tool set from config defaults plus `--add-tool`/`--remove-tool`; `update` detects/reconciles workspace tools (prompting in CLI).
- `tkt/_environment.py`: `Environment` gains access to the configured default tool list.
- `tkt/rubin.py`: `RubinEnvironment` exposes `default_tools` from config.
- `local.json`: add `default_tools` key (default list moved here from the CLI).
- `tkt/_workspace.py`: `Workspace.update` gains the ability to add tools; `_write_tools` already handles newly added tools.
- No packaging/dependency changes.

## Breaking Changes

None.
