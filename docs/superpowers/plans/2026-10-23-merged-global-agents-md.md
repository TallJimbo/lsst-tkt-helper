# Merged global `AGENTS.md` for Zed & OpenCode — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `tkt install-zed-agent` and `tkt install-opencode-agent` generate each harness's global `AGENTS.md` by concatenating a new cross-harness `harnesses/shared/AGENTS.md` with that harness's own instructions file.

**Architecture:** One private helper in `tkt/install.py` (`_install_merged_agents_md`) reads an ordered list of source files, normalizes them, and atomically writes the merged result to the harness's global-instructions path — replacing symlinks and stale generated copies. Both installers call it. No include mechanism, no runtime markdown parsing.

**Tech Stack:** Python 3.13, `click`, `pytest` (tmp_path fixtures), `ruff` (line-length 110, doc-length 79, numpy docstrings), `mypy`.

**Spec:** `docs/superpowers/specs/2026-10-23-merged-global-agents-md-design.md` — read it together with this plan. It carries the decisions this plan implements (clobber policy, byte-exact normalization, heading-blindness, drift from the original handoff).

```python
def _install_merged_agents_md(sources: list[str], dest: str, *, dry_run: bool) -> None:
    """Concatenate the existing ``sources`` (in order) into ``dest``.

    Sources are stripped of surrounding whitespace, joined by one blank line,
    and terminated by exactly one newline.  A symlink at ``dest`` (correct,
    stale, or broken) is replaced; a real file with identical bytes is left
    untouched; a real file whose bytes differ is replaced with a warning; a
    non-file (e.g. a directory) is refused.  Writes nothing when no source
    exists.  The write is atomic (mkstemp in the dest dir + os.replace).
    """
    sections: list[str] = []
    for src in sources:
        if not os.path.isfile(src):
            logging.info(f"Skipping missing agents source {src}")
            continue
        with open(src, encoding="utf-8") as f:
            sections.append(f.read().strip())
    if not sections:
        logging.info(f"No agents sources present; leaving {dest} alone")
        return
    data = ("\n\n".join(sections) + "\n").encode("utf-8")
    if os.path.islink(dest):
        logging.warning(f"Replacing symlink {dest} -> {os.readlink(dest)}")
    elif os.path.lexists(dest):
        if not os.path.isfile(dest):
            logging.warning(f"Refusing to replace non-file {dest}")
            return
        with open(dest, "rb") as f:
            if f.read() == data:
                logging.info(f"OK: {dest} up to date")
                return
        logging.warning(f"Replacing stale generated copy {dest}")
    logging.info(f"{'Would write' if dry_run else 'Writing'} {dest}")
    if dry_run:
        return
    fd, tmp = tempfile.mkstemp(dir=os.path.dirname(dest), prefix=".AGENTS.md.")
    try:
        with os.fdopen(fd, "wb") as f:
            f.write(data)
        # mkstemp yields 0600; this file is meant to be world-readable.
        os.chmod(tmp, 0o644)
        os.replace(tmp, dest)
    except BaseException:
        os.unlink(tmp)
        raise
```

Three details to preserve exactly — they are decisions, not style: the `0o644` chmod (`mkstemp` creates `0600` and nothing else in this repo sets modes), the non-file refusal (mirrors `_ensure_link`'s "Refusing to replace non-symlink" instead of letting `os.replace` raise `IsADirectoryError`), and the neutral "Replacing symlink" wording (a legacy install's link to `rules.md` was *correct* and must still be replaced).

- [ ] **Step 3: Verify the real tree merges, without touching `~/.config`**

Install against the real repo root into a throwaway `HOME`. This is the check that the seed files exist, are non-empty, and both appear — the unit tests cannot catch a missing seed because they build fake repos:

```bash
python - <<'PY'
import os
import tempfile

from tkt.install import install_opencode_agent, install_zed_agent

repo = os.getcwd()
SOURCES = {
    "zed": [("harnesses", "shared", "AGENTS.md"), ("harnesses", "zed", "rules.md")],
    "opencode": [
        ("harnesses", "shared", "AGENTS.md"),
        ("harnesses", "opencode", "AGENTS.md"),
    ],
}

def body(*parts):
    with open(os.path.join(repo, *parts), encoding="utf-8") as f:
        return f.read().strip()

with tempfile.TemporaryDirectory() as home:
    install_zed_agent(repo_root=repo, home=home)
    install_opencode_agent(repo_root=repo, home=home)
    for harness, sources in SOURCES.items():
        dest = os.path.join(home, ".config", harness, "AGENTS.md")
        assert not os.path.islink(dest), dest
        text = open(dest, encoding="utf-8").read()
        # Full equality already pins shared-first and byte-exact normalization;
        # nothing here may hard-code the seed stubs' wording.
        expected = "\n\n".join(body(*parts) for parts in sources) + "\n"
        assert text == expected, (harness, text[:60])
        assert oct(os.stat(dest).st_mode & 0o777) == "0o644", dest
        print(f"{harness}: {len(text)} bytes, both sources merged in order, mode 0644")
PY
```

A missing or empty seed file fails the equality assert, which is exactly what this step guards — the unit tests build fake repos and cannot notice a seed file that was never committed.
